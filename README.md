# GPT Assets Library — Central Hub

This repository serves as a central asset store for multiple GPT chatbots, starting with GPT Alex, GPT Valor, and GPT VYRUS. It contains diagrams, logos, headers, and small chat-mode visuals organized by GPT and subject.

## Structure

- `Alex/` — Contains diagrams and logos for GPT Alex. Within this folder, subject-specific subfolders organize diagrams, and `assets/logos` holds Alex-related icons.
- `Valor/` — Contains logos and assets for GPT Valor. See `Valor/index.md` for details on available logos and references to Valor's architecture documentation.
- `vyrus_assets/` — Contains VYRUS welcome header and mode badge assets.
- `.gitignore` and `LICENSE.txt` are included as standard project files.

## Purpose

This structure ensures GitHub correctly tracks all GPT-specific folders while keeping the repository modular. Future updates will populate the folders with diagrams and icons for each GPT as needed.
